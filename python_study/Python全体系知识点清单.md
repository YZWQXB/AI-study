# Python 全体系学习知识点清单

> 配套代码：`python_study/` 目录，一章一目录，一小节一个可独立运行的 `.py` 文件。
> 运行环境：Python 3.12+，仅使用标准库，无需安装第三方依赖。
> 适用对象：具备 C++ 基础、希望系统掌握 Python 的初学者。

## 一、使用说明

### 1.1 优先级图例

| 标记 | 含义 | 学习动作 |
| --- | --- | --- |
| P0 | 核心必学 | 后续章节直接依赖，必须能脱离资料独立写出并排错 |
| P1 | 重点掌握 | 能熟练使用，能解释适用场景、边界与常见替代方案 |
| P2 | 进阶了解 | 理解概念与用途，实际使用时查阅文档即可 |

### 1.2 掌握要求图例

| 等级 | 判定标准 |
| --- | --- |
| 理解 | 能用自己的话解释概念、用途与限制，能读懂示例 |
| 会用 | 能在示例基础上改造，完成相似的小任务 |
| 熟练 | 能独立编写、调试，并主动处理边界与错误输入 |
| 精通 | 能说明实现原理、时间/内存代价，并在多种写法间做取舍 |

### 1.3 学习方式

1. 按章节顺序推进，先完成所有 P0，再回头补 P1，最后浏览 P2。
2. 每个知识点先运行配套示例，再修改数据与条件观察输出，不要只看不写。
3. 每节末尾的“常见坑点”当作自测题：能解释原因，才算真正掌握。
4. 每章最后一节是综合案例，先自己实现，再对照示例重构。
5. C++ 对比注释只用于建立映射，不要用 C++ 写法硬套 Python 惯用法。

| 异常 | 典型原因 | 排查方向 |
| --- | --- | --- |

## 附录 E 基础编码规范摘要

1. 缩进统一 4 个空格，不使用 Tab。
2. 标识符使用有语义的英文名字；变量与函数用 snake_case，类用 PascalCase，常量用全大写。
3. 每行尽量不超过 79 到 100 个字符，长表达式拆行并加括号。
4. 顶层定义之间空两行，类内方法之间空一行。
5. 导入放在文件顶部，按标准库、第三方、本地模块分组。
6. 函数只做一件事；参数过多时考虑拆分或使用数据类。
7. 捕获具体异常，不用裸 `except:`；错误信息要说明“哪里错、期望什么”。
8. 使用 f-string 格式化；金额计算避免直接用二进制浮点累加。
9. 公共函数写文档字符串，复杂判断写简短注释解释“为什么”。
10. 提交前至少验证正常输入、边界输入、错误输入三类情况。
